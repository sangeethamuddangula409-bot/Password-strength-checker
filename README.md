# Password Strength Checker

## Description
The Password Strength Checker is a Python project that evaluates password security based on length, uppercase and lowercase letters, numbers, special characters, and predictable patterns. It provides a security score, a password rating, and suggestions for improvement.

## Features
- Checks password length and complexity.
- Identifies common and predictable passwords.
- Calculates a security score out of 100.
- Classifies passwords as Weak, Medium, Strong, or Very Strong.
- Provides suggestions to improve password strength.
- Allows repeated checks until the user types `exit`.

## Technologies Used
- Python
- String module
- Conditional statements
- Loops and functions

## How to Run
1. Install Python on your computer.
2. Save the code as `password.py`.
3. Open a terminal in the project folder.
4. Run the command:

   ```bash
   python password.py
   ```

5. Enter a password to check its strength.
6. Type `exit` to close the program.

## Objective
To help users understand password security and encourage the creation of stronger passwords.

## Conclusion
This project demonstrates basic Python programming concepts while promoting awareness of password security.
